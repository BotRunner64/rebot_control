# reBot B601-RS 本地关节控制台

这是运行在机械臂 USB 所在主机上的 WebUI。仅依赖 Linux、Python 3.12+ 和标准库，使用现有 SocketCAN `can0`，无需安装 ROS、Node 或 MotorBridge。

启动：

```sh
cd /home/wubingqian/projects/rebot_control
./run_webui.sh
```

打开 <http://127.0.0.1:8765>。服务仅监听本机。启动、打开页面、刷新状态都不会打开 CAN 或发送电机报文。由你点击“连接机械臂”后才读取电机身份和位置，核对本机校零记录中的 7 个设备标识。

## 手动控制

1. 固定底座并支撑机械臂，点击“连接机械臂”。连接只查询，不使能。
2. 点击顶部“全部使能”，依次以每个关节新读取的当前位置使能保持。过程中不改变目标姿态。若中途失败，已使能的关节继续保持并报告完成范围，不自动撤去其力矩。
3. 使能后直接拖动这一行的滑块，实时更新目标角度，不需要点击执行按钮。未使能时滑块不可用。更新页面读数不会提交目标。
4. 默认 15°/s，可选 5、15、30°/s，直接拖动可选择配置范围内的目标角度，由后端按限速和加速度平滑到达，不受旧版“每次 10°”限制。同一时间只允许一个关节推进目标。夹爪显示的是电机角度，不是开口宽度。
5. “停止并保持”或 Esc 冻结最后发送角度，保留已使能关节的力矩。“全部失能”会撤去力矩，机械臂可能下落；支撑后由你点击。
6. “复位到零位”需要先全部使能，由你点击后，全部关节按所选速度返回已校准的 0°（含夹爪闭合）。它不重新校零，也不自动失能。复位中可随时停止；任一关节故障会冻结整臂目标。完成判定会核对实际角度是否在 1° 内，超时则停止推进目标并报告。

连接后后台进行位置和电压查询；只有你主动使能的关节才周期发送 MIT 保持指令。页面心跳超过 1.5 秒中断（包括后台标签页被浏览器节流），冻结目标、不自动失能或回零。反馈超时、故障、75°C 调试温度阈值、位置偏差异常也会冻结目标并显示错误；保持力矩无法保证，需人工排查。

先手动失能并确认，再断开连接。关闭服务不会自动回零或失能；电机最后保持指令可能继续有效。软件“停止并保持”无法代替独立断电手段。本应用没有自动运行示例、自动回零、改 ID 或校零接口。

## 配置与记录

`config.json` 包含通道、每个电机身份、角度范围、速度限制、MIT 增益。`max_step_deg` 仅用于兼容旧的执行接口，直接拖动不受此项限制。J2/J3 的角度为校零后机械角度，正方向与电机一致。角度范围来自官方 RS 说明，不能代替实际装配的碰撞限位；不同安装和附件仍可能在范围内发生干涉。

拖动请求最多约每 33 ms 发送一次，只保留最新目标；页面约 10 Hz 更新读数，后台控制目标频率为 200 Hz。MIT 指令的位置与速度参考均来自同一条平滑轨迹，保持时速度参考为零。点击停止、失能、断开或页面心跳失联后，旧请求会因控制版本变化被拒绝，避免停止后又执行排队中的角度。

MIT 增益来自 [Seeed 官方 RS 配置](https://github.com/Seeed-Projects/reBotArm_control_py/blob/main/config/rebotarm_rs.yaml)。协议编码对照 [MotorBridge RS 驱动](https://github.com/motorbridge/motorbridge/tree/main/motor_vendors/robstride/src)。本控制台仅实现关节位置保持和手动角度调节，不计算重力补偿、逆运动学或避障。使能时受负载和控制器增益影响，实际位置可能有偏差；页面显示实际反馈与发送目标。

人工操作和保护事件写入 `logs/actions.jsonl`。既有校零记录保存在 `calibration/`，WebUI 不会改写这些记录。

USB 重新插拔或主机重启后，若接口未启动，需在终端手动执行：

```sh
sudo ip link set can0 up type can bitrate 1000000
```

## 仅模拟验证

```sh
./run_webui.sh --simulate --port 8766
/usr/bin/python3 -m unittest discover -v
```

模拟模式不会打开 CAN。所有自动化测试都使用软件电机。不要在真机模式执行自动化点击或运行测试动作。
